# Painel de Bots - Frontend

Frontend completo em React + TypeScript + Tailwind CSS com:
- Dashboard com gráficos
- Gerenciamento de bots, tarefas, SMS, injeta e logs
- Dark mode toggle
- Filtros, busca e paginação
- Upload de ícone para injeta

## Instalação

```bash
npm install
cp .env.example .env
# preencha as variáveis VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, VITE_API_URL
npm run dev
```

## Scripts

- `dev`: servidor de desenvolvimento
- `build`: build de produção
- `preview`: preview da build
